AI Agents Driving Simulation Software

I translate the promise of AI into real gains that remove the grunt work from an R&D simulation campaign, so engineers can spend more time on the actual engineering problem.

The problem I help solve

You've begun work on a computer simulation model in software such as COMSOL Multiphysics®. You know tools like Claude Code and OpenAI Codex are good at coding, so you try out "vibe-engineering." You encounter the following problems:

  • The AI interacts clumsily with the software GUI.
  • AI agents have poor understanding of geometry and meshing.
  • Vibe-engineering gives you questionable physics and boundary condition suggestions.
  • When the AI generates results, you spend more time verifying than if you had just run the simulation yourself.
  • You are using AI as a better search engine but you know you could be doing more with agents.

I help solve your actual engineering/physics problems and do so in a way that equips you to drive further studies with agents that have an auditable log of changes so you can be confident in your results.
