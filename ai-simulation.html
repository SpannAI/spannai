Make Simulations Work for You: Getting More Out of Your COMSOL Multiphysics® Simulations with AI

Sponsored workshop · Friday, October 9, 2026 · 11:00 a.m.

The problem I help solve

You have a working model in COMSOL Multiphysics® simulation software. You know tools like Claude Code and OpenAI Codex are good at coding, so you try out "vibe-engineering." You encounter the following problems:

  • The AI interacts clumsily with the software GUI.
  • AI agents have poor understanding of geometry and meshing.
  • Vibe-engineering gives you questionable physics and boundary condition suggestions.
  • When the AI generates results, you spend more time verifying than if you had just run the simulation yourself.
  • You are using AI as a better search engine but you know you could be doing more with agents.

How I work with COMSOL Multiphysics®

Every COMSOL Multiphysics® model is fully scriptable through the COMSOL® Java API. AI coding agents your team may already pay for can drive parameter sweeps, design variants, supporting analyses, and postprocessing with an auditable log of every change. This works with no new software and no need to know Java yourself.

I help solve your actual engineering/physics problems and do so in a way that equips you to drive further studies with agents that have an auditable log of changes so you can be confident in your results.
