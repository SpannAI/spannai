SpannBridge

SpannBridge lets the Chatbot window in COMSOL Multiphysics® 6.4 use an AI subscription that you already pay for. Instead of an API key, run the Chatbot with either Claude Code on a Claude subscription or OpenAI Codex on a ChatGPT plan. SpannBridge is free, open-source software for Windows, published by Spann Engineering Consulting LLC under the MIT License.

What SpannBridge does

COMSOL Multiphysics® 6.4 simulation software includes a Chatbot window. The Chatbot can connect to any AI service that accepts requests in the format of OpenAI's chat API. Such services normally charge for each request through an API key.

SpannBridge is a free helper script that runs on your PC. The Chatbot connects to SpannBridge as if it were an API service. SpannBridge passes each question to the official command-line program of your AI provider: Claude Code (claude -p) or OpenAI Codex (codex app-server). You sign in to that program with your account. With SpannBridge, you can:

  • Ask modeling questions inside COMSOL Multiphysics®.
  • Ask for code and send it to run in the Java Shell.
  • Use the Java Shell to send error messages back for a fix.
  • Send Model Builder nodes and Graphics window snapshots to the Chatbot and ask about them.

SpannBridge is a helper for the Chatbot window, not an agent. It never operates COMSOL Multiphysics® by itself. Nothing in your model changes until you click Send to Java Shell and Run.

Before you use it

Follow your organization's rules for work data

Everything you type or attach in the Chatbot goes to your AI provider, a third-party company. Many organizations restrict or forbid sending confidential, client, proprietary, or export-controlled information to outside AI services. Check your organization's policy before you send work data. SpannBridge does not filter, redact, or block anything, and it sends nothing to Spann Engineering Consulting LLC. Spann Engineering Consulting LLC also recommends that you turn off model training in the privacy settings of your AI account.

Check your AI provider's rules

SpannBridge is designed to stay within the providers' published rules as of October 2026. But AI providers can change these rules. If you read this from the future, check that your AI provider still allows this. The GitHub page explains how.

Windows only

The Chatbot window in COMSOL Multiphysics® 6.4 runs only on Windows, so SpannBridge is for Windows only.
